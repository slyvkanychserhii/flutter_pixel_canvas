# flutter_pixel_canvas

Пиксельный холст для Flutter: виджет, который занимает всё место родителя и
рисует слои спрайтов, текста и примитивов поверх обычных виджетов.

Это основа. Готовые элементы интерфейса (кнопки, счётчики, поля ввода и так
далее) лежат в отдельном пакете
[flutter_pixel_ui](../flutter_pixel_ui), который строится на этом холсте.

Возможности:

* холст на всё место родителя, целый множитель масштаба (без размытия);
* слои: верхние перекрывают нижние, порядок слоёв и объектов меняется;
* атлас текстур: PNG + JSON (кадры, анимации, шрифты);
* растровый текст шрифтом из атласа (русские и латинские буквы, перенос строк,
  разные цвета в одной строке через теги);
* анимация по кадрам атласа;
* выравнивание по краям холста и привязка к другим объектам;
* спрайт: поворот на 90°, отражение, целое увеличение, прозрачность, подкраска;
* нажатия: какой объект и в каком слое, по пикселям или по прямоугольнику;
* дочерний виджет под графикой и три режима обработки нажатий;
* примитивы: точка, линия, прямоугольник, окружность (контур и заливка).

## Подключение

Требуется Flutter 3.27 или новее.

```yaml
dependencies:
  flutter_pixel_canvas:
    git:
      url: https://github.com/<ваш-аккаунт>/flutter_pixel_canvas.git
      # ref: v0.1.0   # можно закрепить версию тегом
```

Для локальной разработки (репозитории рядом друг с другом):

```yaml
dependencies:
  flutter_pixel_canvas:
    path: ../flutter_pixel_canvas
```

```dart
import 'package:flutter_pixel_canvas/flutter_pixel_canvas.dart';
```

## Быстрый старт

```dart
import 'package:flutter_pixel_canvas/flutter_pixel_canvas.dart';

// 1. Загрузите атлас один раз и освободите, когда он не нужен (atlas.dispose()).
final atlas = await PixelAtlas.load(rootBundle, 'assets/atlas.json');

// 2. Положите холст в место с ограниченным размером (Expanded, SizedBox...).
PixelCanvas(
  scale: 4,                         // один пиксель сцены = 4x4 пикселя экрана
  atlas: atlas,
  background: const Color(0xFF202030),
  layers: const [
    PixelLayer(id: 'world', items: [
      PixelSprite(id: 'hero', frame: 'smiley', x: 10, y: 10),
      PixelText(text: 'Привет!', font: 'main', x: 2, y: 2),
      PixelRect(x: 0, y: 40, width: 60, height: 2, color: Color(0xFF808080)),
    ]),
  ],
  onTap: (tap) => print('${tap.x}, ${tap.y}: ${tap.hit?.id} в слое ${tap.hit?.layerId}'),
)
```

Класс `PixelCanvas` ничего не хранит о вашей сцене: при каждом изменении
передайте ему новый список слоёв (как любому виджету). Слои, объекты и
атлас неизменяемы.

## Основные понятия

**Пиксель сцены.** Все координаты задаются в пикселях сцены. Размер сцены
это размер холста, делённый на `scale` с округлением вниз. Начало координат
(0, 0) в левом верхнем углу виджета; остаток в 1..scale-1 физических пикселей
справа и снизу остаётся пустым.

**Слои.** `PixelLayer(id, items, visible)`. Слои рисуются снизу вверх в
порядке списка, объекты внутри слоя тоже. Типы объектов можно смешивать:
спрайт, поверх него линия, поверх линии текст. Перестановка:
`layers.movedTo('id', index)`, `movedToFront`, `movedToBack` (возвращают
новый список).

**Объекты.** `PixelSprite`, `PixelText` и примитивы `PixelPoint`,
`PixelLine`, `PixelRect`, `PixelCircle`. У каждого есть необязательный `id`,
по которому вы узнаёте объект при нажатии.

## Атлас

Файл описания (JSON) рядом с PNG:

```json
{
  "image": "atlas.png",
  "frames": {
    "red":   {"x": 1,  "y": 1, "w": 16, "h": 16},
    "heart": {"x": 69, "y": 1, "w": 9,  "h": 8}
  },
  "animations": {
    "cycle": {"frames": ["red", "heart"], "fps": 4, "loop": true}
  },
  "fonts": {
    "main": {
      "lineHeight": 13,
      "spacing": 0,
      "glyphs": {"A": "main_0041", "Б": "main_0411"}
    }
  }
}
```

`animations` и `fonts` необязательны. Описание проверяется при загрузке:
ошибка (кадр за границами картинки, анимация с несуществующим кадром и т.д.)
даёт `FormatException` с понятным текстом. Кадры шрифта это обычные кадры
атласа; они белые, а `PixelText.color` их подкрашивает.

## Выравнивание и привязка

Положение спрайта и текста задаётся тремя вещами:

* `align`: точка на самом объекте (`Alignment.topLeft` по умолчанию);
* `anchorAlign`: точка на опоре (по умолчанию та же, что `align`);
* `x`, `y`: смещение в пикселях сцены.

Опора это весь холст или другой спрайт/текст (`anchor: 'id'`). Левый
верхний угол = точка опоры − точка на объекте + смещение, округляется до
целых пикселей.

```dart
PixelText(text: 'Нажми', font: 'main', align: Alignment.topRight, x: -2, y: 2)
PixelSprite(frame: 'heart', align: Alignment.center)
// подпись под объектом 'hero' по его центру:
PixelText(text: 'Герой', font: 'main', anchor: 'hero',
    anchorAlign: Alignment.bottomCenter, align: Alignment.topCenter, y: 2)
```

Если опоры с таким id нет, она не рисуется или образовался цикл, объект
крепится к холсту. Подробности в описании `layoutScene` (lib/pixel/pixel_layout.dart).

## Анимация

```dart
PixelSprite(id: 'blink', frame: 'smiley', animation: 'blink', animationRun: n)
```

`id` у анимированного спрайта обязателен. Анимация стартует, когда спрайт
впервые появляется; чтобы запустить заново, увеличьте `animationRun`.
Без зацикливания анимация замирает на последнем кадре. Когда все анимации
доиграли, холст не перерисовывается.

## Свойства спрайта

`quarterTurns` (поворот по часовой на 90° · n), `flipX`, `flipY`, `zoom`
(целое увеличение), `opacity`, `tint`. Порядок: отражение, поворот,
увеличение. Произвольные углы не поддерживаются намеренно: пиксельная
графика при них теряет чёткость.

## Нажатия

`onTap(PixelTap)` сообщает пиксель сцены и `PixelHit` (слой, объект, его
`bounds` на сцене) или `hit: null`. Что считается попаданием, задаёт
`hitArea`: `PixelHitArea.pixels` (только непрозрачные пиксели, по умолчанию
у спрайта) или `bounds` (весь прямоугольник, по умолчанию у текста).
У анимированного спрайта проверяется показанный кадр.

## Дочерний виджет

```dart
PixelCanvas(
  touchMode: PixelTouchMode.graphicsOnly,
  child: Scaffold(...),   // графика рисуется поверх него
  layers: ...,
)
```

Чтобы графика была над целым экраном, оберните холстом весь экран.
Режимы нажатий (`PixelTouchMode`): `capture` (холст ловит всё),
`graphicsOnly` (только нажатия на графику, остальное достаётся виджетам),
`transparent` (виджетам достаётся всё, холст тоже узнаёт о нажатии).

## Цветной текст

Параметр `markup: true` у `PixelText` включает теги цвета. Цвет: `#RGB`, `#RRGGBB`, `#AARRGGBB` или имя (red, green, blue, yellow, orange, white, black, gray). Теги вкладываются, `<<` даёт символ `<`, непонятный тег остаётся в тексте как есть. Без `markup` текст не меняется.

```dart
PixelText(text: 'Урон: <color=red>-25</color>, лечение: <color=#4CAF50>+10</color>',
    font: 'main', markup: true)
```

## Устройство

| Файл (lib/src) | Что делает |
|---|---|
| pixel_canvas.dart | виджет и RenderObject, часы анимации, кэш сцены |
| pixel_objects.dart | объекты слоёв (sealed-классы) |
| pixel_layer.dart | слои и перестановка |
| pixel_atlas.dart | загрузка и проверка атласа, анимации, шрифты |
| pixel_layout.dart | выравнивание и привязки |
| pixel_text_layout.dart | раскладка текста по глифам |
| pixel_markup.dart | разбор тегов цвета в тексте (`<color=…>`) |
| pixel_rasterize.dart | примитив → пиксели (Брезенхэм, окружность) |
| pixel_scene.dart | готовая сцена: раскладка + команды рисования (кэшируется) |
| pixel_hit_test.dart | поиск объекта под нажатием |

Публичное API перечислено в `lib/flutter_pixel_canvas.dart`, остальное
внутреннее.

Рисование идёт одним `drawRawAtlas` на пачку подряд идущих спрайтов и
глифов; отражённые спрайты и примитивы рисуются отдельно, порядок
сохраняется. Сцена пересобирается только при смене списка слоёв, атласа,
размера или кадров анимации.

## Ограничения

* Список слоёв сравнивается по ссылке: новый список при каждой пересборке
  пересобирает сцену (для анимации холста это не так).
* Отражённых спрайтов лучше немного: каждый рисуется отдельной командой.
* Объекты за пределами сцены не отсекаются заранее.
* Нет вращения на произвольный угол и дробных координат.
